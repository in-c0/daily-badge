Today, from every pack

    Bring your own messages

    Put a JSON file in any public GitHub repo or gist and point the badge at it. No fork, no pull request.

    ?pack=gh:YOUR-USER/YOUR-REPO/messages.json

["Ship it", "Fix it", "Ship it again"]

    A list rotates by day of the year. An object keyed like "December 25" is date-specific. Files up to 64 KB, refreshed hourly. If the file is missing the badge says so in red rather than going quiet.

    As text, not an image

    If you would rather have today's line as real text in your README, the GitHub Action rewrites a marked block once a day. Add <!-- daily-badge:start --> and <!-- daily-badge:end --> to your profile README, then:

    - uses: in-c0/daily-badge@v2
  with:
    pack: dev-humor
    tz: Australia/Sydney

    How it works

    The badge is an SVG computed at the edge by a Cloudflare Worker. Each response is cached until your local midnight, then the next message appears. Nothing about you is stored. The renderer is a port of Shields.io's, so it looks the same as the badges you already have.
